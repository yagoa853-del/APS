# 🎓 Análise e Projeto de Sistemas - UDF

Este repositório foi criado para organizar as anotações, exercícios e projetos da disciplina de **Análise e Projeto de Sistemas** do curso de Sistemas de Informação (Bacharelado) no Centro Universitário UDF.

## 📝 Detalhes da Disciplina
* **Instituição:** Centro Universitário UDF
* **Curso:** Sistemas de Informação (Bacharelado)
* **Semestre:** 2º Semestre / 2026
* **Carga Horária:** 60 horas
* **Professor(a) Responsável:** Kadidja Valeria Reginaldo De Oliveira

## 🎯 Objetivos do Curso
* Estudar conceitos e processos de Engenharia de Software.
* Desenvolver pensamento crítico orientado a objetos.
* Praticar a criação de artefatos de sistemas.

---

## 📚 Conteúdo Programático

### Unidade I: Introdução e Metodologia
* Apresentação do plano de ensino.
* Alinhamento de cronograma e bibliografia.

### Unidade II: Conceitos Fundamentais
* Introdução à Engenharia de Software.
* Tipos de modelagem de sistemas.
* Uso de ferramentas CASE para diagramas UML.

### Unidade III: Engenharia de Requisitos
* Requisitos Funcionais (RF).
* Requisitos Não Funcionais (RNF).
* Técnicas de elicitação e extração.
* Especificação de Casos de Uso.

### Unidade IV: Documentação UML 2.0
* Diagrama de Casos de Uso.
* Diagrama de Classes.
* Diagrama de Sequência.
* Diagrama de Atividades.
* Diagrama de Objetos.

### Unidade V: Aplicação Prática
* Criação de documentação completa de projetos.
* Modelagem de estudos de caso baseados em problemas reais.

---

## 💯 Critérios de Avaliação
A Nota Final (NF) é composta pelo somatório de duas avaliações:
* **Avaliação Regimental (A1):** Vale até 5,0 pontos.
* **Avaliação Docente (A2):** Vale até 5,0 pontos.

$$\text{Nota Final} = A1 + A2$$

* **Média para aprovação:** Igual ou superior a 6,0 pontos.
* **Frequência mínima:** 75% de presença nas aulas.
