# 🏢 Sistema de Gerenciamento de Academia - APS

## 📋 Descrição do Projeto

Repositório de atividades práticas referentes à disciplina de **Análise e Projeto de Sistemas (APS)**, onde desenvolvemos a especificação completa de um **Sistema de Gerenciamento de Academia** a partir de conceitos de elicitação, análise e modelagem de requisitos.

---

## 5W - Visão Geral do Projeto

### **WHAT (O QUÊ?)**
**O que é o projeto?**

Um sistema de software para gerenciamento completo de operações de uma academia, contemplando:
- ✅ Cadastro e gestão de alunos
- ✅ Gerenciamento de planos de assinatura
- ✅ Reserva e cancelamento de aulas
- ✅ Controle de pagamentos
- ✅ Consulta de dados e histórico de reservas
- ✅ Controle de acesso por perfil de usuário

### **WHY (POR QUÊ?)**
**Por que fazer este projeto?**

- 📚 **Aprendizado Acadêmico:** Aplicar conceitos de Engenharia de Software na especificação de requisitos
- 🎯 **Prática Profissional:** Seguir metodologias reais de levantamento e documentação de requisitos
- 🤝 **Trabalho em Equipe:** Desenvolver habilidades colaborativas na análise de sistemas
- 📖 **Base para Próximas Etapas:** Criar especificação sólida como fundação para casos de uso e design

## 🎨 Dinâmica do Desenho

Na Unidade 1, realizamos uma **dinâmica de prototipagem rápida** onde cada estudante desenhou uma tela de aplicativo em 10 minutos.

**Sistema Proposto:** Facul Resolve  
**Funcionalidade:** Registrar problemas que ocorrem na instituição

### Elementos da Tela
- Tipo de problema (dropdown)
- Local do problema
- Descrição detalhada
- Upload de foto
- Nível de urgência (Alta/Média/Baixa)
- Botão de envio

Cada aluno criou sua própria versão visual e funcional diferente para a mesma proposta.
