# 🏢 Sistema de Gerenciamento de Academia - APS

## 📋 Descrição do Projeto

Repositório de atividades práticas referentes à disciplina de **Análise e Projeto de Sistemas (APS)**, onde desenvolvemos a especificação de um **Sistema de Gerenciamento de Academia** a partir dos conceitos de elicitação, análise, documentação e validação de requisitos.

O projeto tem como objetivo especificar as principais funcionalidades e características necessárias para um sistema capaz de auxiliar no gerenciamento de alunos, planos, aulas, reservas e pagamentos de uma academia.

---

## 5W - Visão Geral do Projeto

### **WHAT (O QUÊ?)**
**O que é o projeto?**

Um sistema de software para gerenciamento das principais operações de uma academia, contemplando:

- ✅ Cadastro de alunos
- ✅ Consulta de planos disponíveis
- ✅ Reserva e cancelamento de aulas
- ✅ Cadastro e edição de aulas
- ✅ Cadastro e edição de planos
- ✅ Consulta de pagamentos
- ✅ Consulta de dados cadastrais e reservas
- ✅ Controle de acesso por perfil de usuário

## 🎨 Dinâmica do Desenho

Na Unidade 1, realizamos uma **dinâmica de prototipagem rápida** onde cada estudante desenhou uma tela de aplicativo em 10 minutos.

**Sistema Proposto:** Facul Resolve

**Funcionalidade:** Registrar problemas que ocorrem na instituição

### Elementos da Tela

- Tipo de problema (dropdown)
- Local do problema
- Descrição detalhada
- Upload de foto
- Nível de urgência (Alta/Média/Baixa)
- Botão de envio

Cada aluno criou sua própria versão visual e funcional para a mesma proposta, exercitando conceitos de levantamento de necessidades, definição de funcionalidades e prototipagem de interfaces.

## 📚 Conceitos Aplicados

### Engenharia de Requisitos

- ✅ Elicitação de requisitos
- ✅ Análise e organização de requisitos
- ✅ Documentação estruturada
- ✅ Definição de prioridades
- ✅ Critérios de aceitação
- ✅ Exemplos de utilização
- ✅ Requisitos funcionais e não funcionais

### Qualidade de Requisitos

Um bom requisito deve ser:

- **Claro** - Sem ambiguidades e de fácil compreensão
- **Específico** - Com informações precisas sobre o comportamento esperado
- **Verificável** - Com critérios que permitam confirmar se foi atendido
- **Relevante** - Alinhado aos objetivos e necessidades do sistema
